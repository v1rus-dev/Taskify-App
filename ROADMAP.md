# Taskify Spaces Roadmap

## Post-MVP (Advanced)

1. Activity Feed
- Space/entity event log API.
- UI timeline by space/member/entity.

2. Notifications
- In-app inbox and unread badges.
- Push notifications for assignments/invites/mentions.

3. Space Management Enhancements
- PATCH space metadata.
- Archive/unarchive spaces.

4. Collaboration Depth
- Comments and mentions.
- Threaded discussion under tasks/notes.

5. Notes Editor
- Rich text notes.
- Attachments and media blocks.

6. Automations
- Rules and triggers for repetitive flows.

7. Analytics
- Participation/activity metrics.
- Throughput and completion insights.
