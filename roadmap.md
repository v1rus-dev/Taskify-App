# Taskify Offline-First Roadmap

## Контекст

Серверная часть и онлайн-сценарии временно заморожены.  
Цель roadmap: сделать Taskify полноценным личным планером, который стабильно работает локально без доступа к сети.

Фокус текущего цикла: **личный офлайн-планер**.

---

## Текущее состояние (as-is)

- Локальная модель данных и хранилище уже есть (Drift + feature-first архитектура).
- Основные экраны `Home`, `Tasks`, `Activity`, `Profile` работают с локальными данными.
- Локальные уведомления и напоминания уже реализованы.
- Сетевой sync фактически выключен флагом `isSyncNetworkEnabled = false`.
- Модуль `Spaces` пока заглушка.
- Часть social/auth сценариев завязана на сеть и сейчас не должна быть главным пользовательским потоком.

Ключевые наблюдения:
- На Home фильтрация задач по дате опирается на `createdAt`, а не на плановую `task.date` (нужно исправить).
- В модели есть recurrence/reminder, но полный жизненный цикл recurring-задач в UX еще не завершен.

---

## Целевое состояние (to-be)

Taskify в офлайне должен давать законченный ежедневный сценарий:

- Быстрое создание и редактирование задач.
- Представления `Inbox`, `Today`, `Upcoming`.
- Поиск и фильтры по локальной БД.
- Повторяющиеся задачи с корректным созданием следующих экземпляров.
- Надежные локальные уведомления.
- Архив завершенных задач.
- Backup/Restore через локальный JSON экспорт/импорт.
- Локальные проекты/списки вместо текущей заглушки `Spaces`.

## Этапы реализации

| Этап | Цель | Изменения | Выход |
|---|---|---|---|
| P0 Stabilization | Убрать критичные UX-противоречия | Исправить фильтрацию Home по `task.date`; добавить явный индикатор локального режима; скрыть/ограничить сетезависимые flows | Стабильный базовый офлайн UX |
| P1 Core Planner UX | Сделать повседневное использование удобным | Добавить `Inbox/Today/Upcoming`; локальный поиск; фильтры по тегам/статусу; bulk actions | Полноценный ежедневный офлайн планер |
| P2 Recurrence & Reminder | Завершить цикл планирования на будущее | Реализовать автогенерацию recurring задач при completion; доработать edge-cases напоминаний | Повторяемые задачи и уведомления без ручной рутины |
| P3 Offline Projects | Закрыть пробел `Spaces` | Превратить `Spaces` в локальные Projects/Lists; добавить сортировку/приоритет/позиции задач | Структурирование задач по проектам офлайн |
| P4 Data Safety | Надежность и переносимость данных | Экспорт/импорт JSON; проверка целостности task/subtask/tag; сценарии восстановления | Контроль данных без облака |

### P0 checklist

- [ ] Исправлена фильтрация Home по `task.date`.
- [ ] Добавлен понятный статус "локальный режим" в интерфейсе.
- [ ] Сетевые/замороженные сценарии не мешают основному UX.

### P1 checklist

- [ ] Реализованы представления `Inbox`, `Today`, `Upcoming`.
- [ ] Работает поиск по title/description/tags.
- [ ] Добавлены массовые операции (complete/move/delete).

### P2 checklist

- [ ] При завершении recurring задачи корректно создается следующий инстанс.
- [ ] Напоминания корректны для all-day и timed задач.
- [ ] Поведение валидно после перезапуска приложения.

### P3 checklist

- [ ] `Spaces` заменен на рабочие локальные Projects/Lists.
- [ ] Задача может принадлежать проекту/списку.
- [ ] Поддержаны сортировка и приоритеты.

### P4 checklist

- [ ] Экспорт и импорт данных выполняются локально.
- [ ] После restore структура данных консистентна.
- [ ] Ошибки импорта обрабатываются предсказуемо и безопасно.

## Конкурентный бенчмарк и что заимствуем

| Продукт | Сильная сторона | Что берем в Taskify (offline) |
|---|---|---|
| Todoist | Today/Upcoming/Filters, recurring | Структурированные представления и фильтры |
| TickTick | Календарный фокус + привычки/ритм | Бесшовная работа с датами и регулярностью |
| Microsoft To Do | Простота ежедневного сценария | Минимальный friction для daily planning |
| Any.do | Напоминания и календарный сценарий | Четкие reminder-флоу и обзор дня |

Принцип внедрения: заимствуем паттерны UX, но реализуем только те, что работают локально без сервера.

## KPI и Definition of Done

| Метрика | Цель |
|---|---|
| Offline success rate ключевых сценариев | 100% в airplane mode |
| Crash-free rate основных экранов | >= 99.5% |
| Время открытия Home до интерактивности | <= 1.5 сек на среднем устройстве |
| Время поиска по локальным задачам | <= 200 мс для типичных объемов |
| Успешный backup/restore | 100% на валидном JSON |

Definition of Done на релиз офлайн-версии:

- Пользователь может вести задачи полностью без сети.
- После перезапуска данные, фильтры и уведомления остаются консистентными.
- Нет критичных UX-ложных ожиданий про облачную синхронизацию.
- Покрыты unit + integration тестами критичные потоки.

## Риски и зависимости

| Риск | Влияние | Митигирующие действия |
|---|---|---|
| Рост сложности схемы БД | Высокое | Поэтапные миграции и тесты миграций |
| Регресс в датах/таймзонах | Высокое | Единые date/time utility и тесты edge-cases |
| Перегруженность Home при росте данных | Среднее | Индексация, оптимизация запросов и стримов |
| Смешение офлайн и legacy online UX | Среднее | Явная продуктовая граница офлайн режима |

Зависимости реализации:

- Drift миграции и тесты.
- Уточнение UX-стандарта для новых представлений (`Inbox/Today/Upcoming`).
- Согласованный формат JSON для backup/restore.
